# 🎁 ふるさと納税 やりくり帳

楽天ふるさと納税の返礼品を登録して、**寄付済み合計・残り枠・おすすめの組み合わせ**を自動計算するツールです。
1ファイル（`index.html`）で動き、データは各自のブラウザ内に保存されます。

## できること

- 上限額の入力（年収からの簡易目安計算つき）
- 返礼品の追加
  - **URL貼り付け**（楽天アプリの「共有」テキストをそのまま貼ってOK、複数まとめて可）※中継サーバーが必要
  - **ブックマークレット**（PC。楽天の商品ページで1クリック。設定不要）
  - 手入力
- 容量違い（150g / 500g / 1kg…）がある返礼品は、取り込み時に選択。あとから切り替えも可
- 寄付済み／候補の管理、ワンストップ特例の自治体数カウント（5自治体まで）
- **組み合わせ提案**：残り枠に収まる組み合わせを上位5件表示
  - 「枠を使い切る重視」／「欲しい度（★）重視」
  - 「必ず入れる」指定、ワンストップ特例（5自治体以内）の制約、同じ品を複数口
- 年度ごとのデータ、JSONで書き出し／読み込み

## 公開してみんなで使う（無料）

### 1. ツール本体を GitHub Pages で公開

1. GitHub にログインし、新しいリポジトリ（例: `furusato-yarikuri`、Public）を作る
2. `index.html` をアップロード（「Add file → Upload files」）
3. Settings → Pages → Branch を `main` / `(root)` にして Save
4. 数分後 `https://<ユーザー名>.github.io/furusato-yarikuri/` で公開される

このURLを共有すれば、誰でも使えます（データは使う人それぞれのブラウザに保存）。

### 2. URL貼り付けの自動取得を有効にする（任意・無料）

ブラウザだけでは楽天のページを読み取れないため、Cloudflare Workers に小さな中継サーバーを置きます。

1. https://dash.cloudflare.com/ で無料アカウントを作成
2. 「Workers & Pages → 作成 → Worker を作成」→ 名前（例: `furusato-proxy`）→ デプロイ
3. 「コードを編集」で中身を `worker.js` に置き換える
   - 先頭の `ALLOWED_ORIGINS` を自分の GitHub Pages のオリジン（例: `https://yourname.github.io`）に書き換える
4. デプロイすると `https://furusato-proxy.<アカウント名>.workers.dev` のようなURLができる
5. `index.html` の設定（⚙ 設定 → 中継サーバーのURL）に入れる

みんなに最初から使ってもらうには、`index.html` 冒頭付近の `const DEFAULT_WORKER_URL = "";` にこのURLを書いておくと、設定なしで自動取得が使えます。
無料枠は1日10万リクエストなので、個人〜知人規模なら十分です。

## スマホで使う

公開したURLをスマホのブラウザで開けばそのまま使えます（画面は縦幅に合わせて並び替わります）。

- **Android（Chrome）**：メニューの「アプリをインストール／ホーム画面に追加」をすると、楽天アプリの**共有 → やりくり帳**で商品を直接送れます（`manifest.json` の share_target）
- **iPhone（Safari）**：共有先としては選べないので、楽天アプリで「リンクをコピー」→ やりくり帳の「URLを貼る」に貼り付け
- どちらも**自動で金額を読み取るには中継サーバーの設定が必要**です（未設定なら金額のみ手入力）
- ブックマークレットはPC向けです
- データはブラウザごとに保存されるので、PCとスマホで共有したいときは ⚙ 設定 の書き出し／読み込みを使ってください

`sw.js` はホーム画面に追加したときのオフライン表示用です。

## 注意

- 上限額の目安計算は「給与所得のみ・住宅ローン控除や医療費控除なし」の簡易計算です
- 楽天の商品情報は取り込み時点のもので、ページの仕様変更で読み取れなくなることがあります（その場合は手入力で使えます）
- 実際の寄付手続きは楽天市場で行ってください
